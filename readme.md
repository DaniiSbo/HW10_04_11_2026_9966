# Домашнее задание к работе 10

## Условие задачи
Составить программу, которая для заданной фигуры — верхней половины кольца между двумя концентрическими окружностями (вариант 14, фигура из ДЗ 9) — предлагает меню выбора одной из операций:

1) рассчитать площадь;
2) вывести определение фигуры;
3) нарисовать фигуру;
4) вывести параметры фигуры;
5) сравнить две фигуры по площади.

Внешний радиус **R** и внутренний радиус **r** пользователь задаёт при запуске, а символ рисования запрашивается только при выборе пункта «нарисовать фигуру». Фигура задаётся условиями **y ≥ 0** и **r ≤ √(x² + y²) ≤ R**.

## 1. Алгоритм

### Основная программа
1. **Начало**
2. Ввести внешний радиус **R** и внутренний радиус **r**.
3. Проверить условие **0 < r < R**:
   - если условие не выполняется, вывести сообщение об ошибке и завершить программу;
   - иначе перейти к следующему шагу.
4. Вывести меню и ввести номер операции **choice**.
5. Если **choice = 1**, вычислить площадь полукольца по формуле **S = π(R² − r²) / 2** и вывести её.
6. Если **choice = 2**, вывести определение полукольца.
7. Если **choice = 3**, ввести символ рисования **symbol** и нарисовать фигуру этим символом.
8. Если **choice = 4**, вывести внешний радиус, внутренний радиус и площадь фигуры.
9. Если **choice = 5**, ввести радиусы второй фигуры, проверить их и вывести площади обеих фигур и разность площадей.
10. Если **choice = 0**, завершить работу.
11. Если введён другой номер, вывести сообщение об ошибке.
12. Если **choice ≠ 0**, вернуться к выводу меню.
13. **Конец**

### Функция вычисления площади
Функция `area_half_ring(R, r)` возвращает значение **π(R² − r²) / 2**.

### Функция рисования
Фигура рисуется на постоянном поле **61 × 15** символов. Одна ячейка поля соответствует **R / 30** единиц длины, поэтому фигура всегда сохраняет пропорции и не зависит от абсолютных размеров радиусов. Координаты ячейки обозначим **x** и **y**; они изменяются в пределах **−30 ≤ x ≤ 30** и **1 ≤ y ≤ 29**.

Функция `draw_half_ring(R, r, symbol)`:

- для **y** от **29** до **1** с шагом **−2**:
  - для **x** от **−30** до **30**:
    - если **900r² ≤ (x² + y²)R² ≤ 900R²**, вывести **symbol**, иначе вывести пробел;
  - перейти на новую строку.

Неравенство получается из условия **r² ≤ (x·R/30)² + (y·R/30)² ≤ R²**, умноженного на **900**. Шаг по **y** равен 2, потому что символ в консоли примерно вдвое выше, чем шире. Корень при рисовании не нужен.

Постоянное поле выбрано специально. При фиксированном масштабе 5 ширина строки равнялась бы **10R + 1** символов: при **R = 100** это 1001 символ, строка не помещается в окно консоли и переносится, из-за чего рисунок рассыпается на части. Кроме того, при больших радиусах произведение **x·x** или **R·5** переполняло бы тип `int`. Поле 61 × 15 даёт ровно ту фигуру, которая была получена в ДЗ 9 при **R = 6**, **r = 4**, но остаётся компактным при любых радиусах.

Если **r** очень близко к **R**, кольцо оказывается тоньше одной ячейки поля, поэтому его изображение может стать пунктирным. Это ограничение символьной графики, а не ошибка расчёта: площадь и параметры в этом случае вычисляются правильно.

### Остальные функции
- `print_definition()` выводит определение полукольца.
- `print_params(R, r)` выводит название фигуры, её радиусы и площадь.
- `compare_half_rings(R1, r1, R2, r2)` возвращает разность площадей первой и второй фигур.

## 2. Реализация программы

Проект разделён на три файла, как в примере `CW10_18_10_2026`:

- `figures.h` — объявления собственных функций;
- `figures.c` — определения собственных функций;
- `main.c` — функция `main` с меню.

В заголовочном файле размещены только объявления, а тела функций находятся в `figures.c`. Если поместить определения в `.h` и подключить его в нескольких `.c` файлах, линковщик сообщит об ошибке повторного определения. Заголовочный файл подключается директивой `#include "figures.h"` и в `main.c`, и в `figures.c`. В `CMakeLists.txt` файл `figures.c` добавлен в `add_executable`.

### Файл figures.h

```c
double area_half_ring(int r_out, int r_in);
void draw_half_ring(int r_out, int r_in, char symbol);
void print_definition(void);
void print_params(int r_out, int r_in);
double compare_half_rings(int r1_out, int r1_in, int r2_out, int r2_in);
```

### Файл figures.c

```c
#include <stdio.h>
#include "figures.h"

#define PI 3.14159265358979323846
#define DRAW_HALF 30

double area_half_ring(int r_out, int r_in) {
    return PI * (r_out * r_out - r_in * r_in) / 2.0;
}

void draw_half_ring(int r_out, int r_in, char symbol) {
    int x, y;
    double inner_limit = (double)DRAW_HALF * DRAW_HALF * r_in * r_in;
    double outer_limit = (double)DRAW_HALF * DRAW_HALF * r_out * r_out;

    for (y = DRAW_HALF - 1; y >= 1; y -= 2) {
        for (x = -DRAW_HALF; x <= DRAW_HALF; x++) {
            double cell = (double)(x * x + y * y) * r_out * r_out;

            if (cell >= inner_limit && cell <= outer_limit)
                putchar(symbol);
            else
                putchar(' ');
        }
        putchar('\n');
    }
}

void print_definition(void) {
    puts("Полукольцо — часть кольца, ограниченная двумя концентрическими");
    puts("окружностями с общим центром и расположенная по одну сторону");
    puts("от прямой, проходящей через этот центр.");
}

void print_params(int r_out, int r_in) {
    puts("Фигура: верхняя половина кольца");
    printf("Внешний радиус: %d\n", r_out);
    printf("Внутренний радиус: %d\n", r_in);
    printf("Площадь: %.2f\n", area_half_ring(r_out, r_in));
}

double compare_half_rings(int r1_out, int r1_in, int r2_out, int r2_in) {
    return area_half_ring(r1_out, r1_in) - area_half_ring(r2_out, r2_in);
}
```

### Файл main.c

```c
#define _CRT_SECURE_NO_DEPRECATE

#include <stdio.h>
#include <stdlib.h>
#include "figures.h"

int main(void) {
    int r_out, r_in;
    int r2_out, r2_in;
    int choice;
    char symbol;

    system("chcp 65001 > nul");

    puts("Введите внешний радиус полукольца");
    scanf("%d", &r_out);
    puts("Введите внутренний радиус полукольца");
    scanf("%d", &r_in);

    if (r_out <= 0 || r_in <= 0 || r_in >= r_out) {
        puts("Ошибка: должно выполняться условие 0 < внутренний радиус < внешний радиус");
        system("pause");
        return 1;
    }

    do {
        puts("");
        puts("Меню:");
        puts("1 - рассчитать площадь");
        puts("2 - вывести определение фигуры");
        puts("3 - нарисовать фигуру");
        puts("4 - вывести параметры фигуры");
        puts("5 - сравнить с другой фигурой по площади");
        puts("0 - выход");
        puts("Введите номер операции");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                printf("Площадь полукольца: %.2f\n", area_half_ring(r_out, r_in));
                break;
            case 2:
                print_definition();
                break;
            case 3:
                puts("Введите символ для рисования");
                scanf(" %c", &symbol);
                draw_half_ring(r_out, r_in, symbol);
                break;
            case 4:
                print_params(r_out, r_in);
                break;
            case 5:
                puts("Введите внешний и внутренний радиусы второй фигуры");
                scanf("%d %d", &r2_out, &r2_in);
                if (r2_out <= 0 || r2_in <= 0 || r2_in >= r2_out) {
                    puts("Ошибка: для второй фигуры должно выполняться условие 0 < внутренний радиус < внешний радиус");
                } else {
                    printf("Площадь первой фигуры: %.2f\n", area_half_ring(r_out, r_in));
                    printf("Площадь второй фигуры: %.2f\n", area_half_ring(r2_out, r2_in));
                    printf("Разность площадей: %.2f\n", compare_half_rings(r_out, r_in, r2_out, r2_in));
                }
                break;
            case 0:
                puts("Работа завершена");
                break;
            default:
                puts("Нет операции с таким номером");
        }
    } while (choice != 0);

    system("pause");
    return 0;
}
```
